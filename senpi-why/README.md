# senpi-why

The positioning skill. Answers *"what makes Senpi different?"* / *"why Senpi?"* / *"Senpi vs other
trading apps?"* the way Senpi wants to be understood — **led by value, machinery under the hood, no
outcome promises.**

- **`SKILL.md`** — how the agent should answer (the one-liner, the three proof pillars, the voice
  guardrails, the answer shape).
- **`references/overview-positioning.md`** — the canonical consumer-facing prose, ready to sync into
  the `senpi://guides/senpi-overview` guide so the platform overview itself leads with the USP.

No engine — pure narration governance. For exact live numbers (current fee tier, market count) the
agent calls the existing tools (`get_loyalty_tiers`, `market_list_instruments`).
